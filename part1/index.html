Normal Sequence Diagram

  • On an HTTP POST request to the server address new_note. The server responds with HTTP status code 302

    The server responds with HTTP status code 302, with which the server asks the browser to make a new HTTP GET request to the address defined in the Location header.

  • The browser reloads the Notes page, the reload causes three more HTTP requests:

      Getting the stylesheet (main.css)
      The JavaScript code (main.js)
      The raw data for the notes (data.json)

Single page application diagram

  • POST Request: The POST request to the new_note_spa address contains the new note as JSON data.

  • Content-Type Header: The Content-Type header of the request tells the server that the data included is represented in JSON format.

  • Server Response: The server responds with a 201 Created status code, using the JavaScript code it got from the server to handle the data to display.

Single page application diagram - create note

  • The user enters a new note into the application form and clicks the "Save" button.

  • The POST request to the "new_note_spa" address contains the new note as JSON data.

  • The "Content-Type" header in the request tells the server that the included data is represented in JSON format.

  • The server processes the request and saves the new note to the database.

  • The server responds with the "201 Created" status code and returns the newly created note along with any additional information needed.

  • JavaScript code on the client receives the server's response and updates the user interface to display the new note without reloading the page.
